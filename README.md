## 📌 Description

IBTVTHIOW Reader is an unofficial, fan-made web reader for the novel **"I Became The Villain The Hero Is Obsessed With"**. Designed for a clean and distraction-free reading experience, it features customizable typography and themes, quick chapter navigation, and offline format exports.

---

## ✨ Key Features

- **Chapter Navigation:** Browse the full chapter list with built-in search, sorting, and pagination.
- **Continue Reading:** Automatically remembers your last read chapter so you can pick up right where you left off.
- **Customizable Reading Settings:** Choose from multiple color themes and fonts, with adjustable font size, line height, font weight, and text alignment.
- **Reader Tools:** Includes a floating toolbar, quick chapter drawer, auto-scroll, and fullscreen mode.
- **Keyboard Shortcuts:** Navigate between chapters and toggle reader tools quickly using keyboard shortcuts.
- **Offline Downloads:** Download the novel in EPUB and PDF formats for offline reading.
- **Local Progress & Settings:** Saves all reading preferences and chapter progress directly in your browser's local storage.
